## 📱 프로젝트 소개

FreshBox는 냉장고 속 재료를 효율적으로 관리하고 음식물 낭비를 줄이기 위해 제작한 앱입니다.

사용자는 재료의 수량과 유통기한을 기록할 수 있으며, 유통기한이 가까워진 재료를 활용한 레시피를 추천받을 수 있습니다.

또한 즐겨찾기와 알림 기능을 통해 자주 사용하는 레시피와 유통기한 정보를 편리하게 관리할 수 있도록 구현했습니다.

## 🚀 기존 앱과의 차별점

기존 레시피 앱은 사용자가 직접 먹고 싶은 음식을 검색하는 방식이 대부분이며, 냉장고 재료의 유통기한까지 함께 관리하는 기능은 부족한 경우가 많습니다.

또한 단순 레시피 검색 기능에 집중되어 있어, 실제 냉장고 속 재료를 얼마나 효율적으로 소비할 수 있는지에 대한 관리 기능은 제한적입니다.

FreshBox는 이러한 문제를 해결하기 위해 다음과 같은 차별점을 제공합니다.

* 유통기한이 임박한 재료를 우선적으로 활용한 레시피 추천
* 재료별 D-Day 계산 및 색상 기반 시각화 제공
* 냉장고 재료 추가 / 수정 / 삭제 기능 제공
* 앱 내부 알림 기록 기능 제공
* OpenAI 기반 재료 조합형 레시피 추천 구조 적용
* 음식물 낭비 감소를 목표로 한 실사용 중심 설계

특히 단순히 “먹고 싶은 메뉴”를 추천하는 것이 아니라, “지금 소비해야 하는 재료”를 중심으로 추천한다는 점에서 기존 레시피 앱과 차별성을 가집니다.

## ✨ 주요 기능

### 🥬 냉장고 재료 관리

* 재료 추가 / 수정 / 삭제
* 수량 및 유통기한 저장
* 유통기한 D-Day 표시
* 유통기한에 따른 색상 변화

### 🍳 레시피 추천

* 냉장고 재료 기반 레시피 추천
* 재료 조합에 따른 다양한 추천 결과 제공
* 레시피 상세 정보 확인 가능

### ❤️ 즐겨찾기

* 원하는 레시피 저장
* 저장된 레시피 다시 확인 가능
* 즐겨찾기 삭제 기능

### 🔔 알림 기능

* 유통기한 임박 재료 감지
* 앱 내부 알림 기록 저장
* D-3 이하 재료 알림 제공
